Features Demonstrated

  • Auto-open on load - Chatbot opens automatically when page loads
  • Session storage - Uses sessionStorage instead of localStorage
  • Streaming mode - Real-time SSE streaming responses (NEW!)
  • Metadata tracking - Sends custom metadata with each request (NEW!)

Configuration

This example uses the following configuration options:

  • autoOpen: true - Opens automatically on page load
  • sessionStorage: true - Uses session storage for conversation persistence
  • enableStreaming: true - Enable real-time streaming responses (NEW!)
  • metadata: {...} - Send custom metadata with each request (NEW!)
  • maxWidth: '500px' - Larger chat window
  • maxHeight: '700px' - Taller chat window
  • position: 'top-right' - Positioned in top-right corner
