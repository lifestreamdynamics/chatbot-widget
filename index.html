Lifestream Chatbot Widget

Embeddable AI-powered chatbot for your website - Development Preview

About This Widget

This is a standalone, embeddable chatbot widget powered by Google Gemini AI. It can be integrated into any website with just a few lines of code.

Look for the chatbot button in the bottom-left corner! Click it to start chatting.

Features

Framework Agnostic

Works with vanilla JS, React, Vue, Angular, or any web framework

Customizable Theme

Full control over colors, positioning, and appearance

Markdown Support

Rich text formatting with code blocks and lists

Session Management

Maintains conversation context across page reloads

Quick Actions

Customizable quick reply buttons for common questions

Responsive Design

Works beautifully on desktop, tablet, and mobile

Quick Start

Add the widget to your website in 3 simple steps:

<!-- 1. Include the CSS -->
<link rel="stylesheet" href="lifestream-chatbot.css">

<!-- 2. Include the script -->
<script src="lifestream-chatbot.iife.js"></script>

<!-- 3. Initialize the chatbot -->
<script>
  initLifestreamChatbot({
    apiUrl: 'https://your-api.com/api/v1',
    apiKey: 'your-api-key'
  });
</script>

Development

This preview is running in development mode. To build for production:

pnpm install
pnpm build

The build will generate optimized files in the dist/ directory.
